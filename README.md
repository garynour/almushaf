# المصحف — القرآن الكريم ومواقيت الصلاة

تطبيق React + Vite، يُحزَّم لأندرويد عبر Capacitor 8.

```bash
npm install
npm run dev        # تشغيل محلي
npm test           # اختبارات المواقيت والإشعارات
npm run build      # نسخة الويب (production)
```

للنشر على Google Play اتبع الدليل: [`docs/PLAY_STORE_GUIDE.md`](docs/PLAY_STORE_GUIDE.md)
