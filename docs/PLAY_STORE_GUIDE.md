# دليل النشر على Google Play — تطبيق «المصحف»

> مهم: كل الخطوات هنا مبنية على ما وجدته وقت الكتابة (نوفمبر 2026). سياسات جوجل تتغير، فراجع صفحات Play Console نفسها عند أي اختلاف.

## 1) ما لم أستطع التحقق منه (اقرأه!)

بيئتي لا تحتوي إنترنت ولا `vite` ولا Android SDK، لذلك:

- لم أبنِ التطبيق فعلياً ولم أجرّبه على جهاز أو محاكي. اختبرتُ **منطق المواقيت والإشعارات** بـ ٢٢ اختباراً ناجحاً (`npm test`)، وفحصتُ الأنواع، لكن الواجهة لم أرها تعمل.
- الـ workflow وسكربت `scripts/android-setup.mjs` اختبرتُ السكربت على مشروع تجريبي فقط. قد يحتاج تعديلاً بسيطاً أول مرة إن تغيّر شيء في قوالب Capacitor.
- نسخ المكتبات (`@capacitor/* ^8` و`@fontsource/* ^5`...) لم أستطع تثبيتها. إن فشل `npm install` أو الـ workflow، أرسل لي نص الخطأ.
- **صوت الأذان الحقيقي**: لم أستطع تنزيل ملفات الأذان. الموجود نغمة تنبيه بسيطة `android-resources/raw/athan.wav` للاختبار. **استبدلها بأذان تملك حقوقه** (انظر القسم 7) قبل النشر.
- **يجب** اختبار APK على هاتف حقيقي قبل الرفع (قائمة الاختبار في القسم 4).

## 2) شريط المتصفح (Address bar)

تطبيق Capacitor هو تطبيق أندرويد حقيقي بداخله WebView، **ليس متصفحاً**، فلا يوجد شريط عنوان إطلاقاً. لا تحتاج لإعداد إضافي. (الشريط يظهر فقط لو فتحت الموقع في Chrome أو استخدمت TWA بدون التحقق من `assetlinks.json`، ونحن لا نستخدم TWA.)

## 3) بناء الملفات (AAB + APK) بدون كمبيوتر قوي

### 3.1 ارفع المشروع إلى GitHub
1. أنشئ حساب على github.com ثم **New repository** باسم `almushaf` واجعله **Private**.
2. ارفع محتويات مجلد المشروع (من داخل الـ zip، **وليس** الـ zip نفسه) عبر **Add file → Upload files**، أو بـ `git push` من الكمبيوتر.
3. تأكد أن المجلد المخفي `.github/workflows` رُفع (إن لم يظهر في الرفع من الموبايل استخدم كمبيوتر).

### 3.2 أنشئ مفتاح التوقيع (مرة واحدة) واحفظه جيداً
في GitHub افتح المستودع → **Code → Codespaces → Create codespace** (مجاني) ثم في الـ Terminal:

```bash
keytool -genkeypair -v -keystore upload.keystore -alias upload \
  -keyalg RSA -keysize 2048 -validity 10000
base64 -w 0 upload.keystore > keystore.b64
```
- ستُسأل عن كلمة سر + اسمك (املأ أي شيء منطقي).
- حمّل `upload.keystore` من الـ Codespace واحفظ نسخة في مكانين (جوجل درايف + فلاشة) مع كلمة السر. **لا ترفعه إلى GitHub أبداً.**
- ستفتح `keystore.b64` وتنسخ محتواه للخطوة التالية، ثم احذف الـ Codespace.

### 3.3 أضف الأسرار (Secrets)
المستودع → **Settings → Secrets and variables → Actions → New repository secret**، وأنشئ ٤:

| الاسم | القيمة |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | محتوى `keystore.b64` |
| `ANDROID_KEYSTORE_PASSWORD` | كلمة سر الـ keystore |
| `ANDROID_KEY_ALIAS` | `upload` |
| `ANDROID_KEY_PASSWORD` | كلمة سر المفتاح (نفس السابقة غالباً) |

### 3.4 شغّل البناء
**Actions → Build Android → Run workflow** (اكتب `version_name` مثل `1.0.0`، و`version_code` = `1`). بعد ~10–15 دقيقة افتح التشغيل الناجح ونزّل **Artifacts** فيه:
- `app-release.aab` ← للرفع على Google Play
- `app-debug.apk` ← للتجربة على هاتفك (فعّل «التثبيت من مصادر غير معروفة»)

> كل رفع جديد على Play يجب أن يكون `version_code` أكبر من السابق (1، ثم 2، ثم 3...).
> أول تشغيل يمرّ على `npm test` وعلى فحص «نسخة إنتاج». إن فشل أحدهما يتوقف البناء مع سبب واضح.

## 4) اختبر الـ APK على هاتفك قبل أي رفع

- [ ] يفتح بدون شريط متصفح، وبشاشة البداية والأيقونة الصحيحة
- [ ] الخطوط العربية (القرآن والتفسير) صحيحة وجميلة، **مع إيقاف الإنترنت**
- [ ] أعلى الشاشة لا يتداخل مع شريط الحالة، وأسفلها مع شريط التنقل (إن تداخل أخبرني)
- [ ] الموقع: «تحديد موقعي» يطلب الإذن ثم يحسب المواقيت، ومقارنتها بتقويم بلدك صحيحة
- [ ] الإشعارات: فعّلها، واسمح بـ «المنبّهات والتذكيرات» إن ظهرت الرسالة، ثم اضغط «تجربة إشعار». **بعدها** اقفل التطبيق تماماً (من المهام الأخيرة) وانتظر أقرب صلاة/تنبيه، وتأكد أنه يصل بصوته
- [ ] أعد تشغيل الهاتف وتأكد أن تنبيه الصلاة التالية يصل
- [ ] التلاوة: شغّل سورة، أوقفها، شغّلها (تكمل من مكانها)، واقفل الشاشة (تعمل مع أزرار شاشة القفل)
- [ ] حجم الخط (إعدادات) يغيّر حجم القراءة
- [ ] زر الرجوع في الهاتف يتصرف بشكل منطقي

> أجهزة Xiaomi/Huawei/Oppo/Samsung قد توقف التطبيق في الخلفية. اطلب من المستخدم: إعدادات الهاتف ← البطارية ← التطبيق ← «بدون قيود».

---

## 4.5) استبدال صوت الأذان بأذان حقيقي (مهم)

- ملف التنبيه: `android-resources/raw/athan.wav`. استبدله بأذان قصير (يفضّل أقل من دقيقة) تملك حقوقه أو مرخّص للاستخدام التجاري، بنفس الاسم `athan.wav`، أو بصيغة mp3 مع تغيير الاسم في `src/utils/nativeNotifications.ts` (`CHANNELS.athan.sound`).
- قنوات الإشعارات في أندرويد **لا تتغير بعد إنشائها على جهاز المستخدم**: لو غيّرتَ الصوت بعد نشر النسخة الأولى، غيّر معرّف القناة من `athan_v1` إلى `athan_v2` في نفس الملف.
- ملفات الأذان داخل التطبيق (الاختيارات الأربعة) تُحمَّل من مستودع GitHub لشخص آخر. الأفضل استبدالها بملفات تملك حقوقها وتضمينها في `public/`.

## 5) تجهيز Google Play Console

### 5.1 الحساب
- أنشئ حساب مطوّر على play.google.com/console (رسوم تسجيل لمرة واحدة، 25$ وقت الكتابة) وأكمل التحقق من الهوية.
- **الحسابات الشخصية الجديدة**: تحتاج **اختباراً مغلقاً بـ 12 مختبراً على الأقل لمدة 14 يوماً متواصلة** قبل أن تتمكن من طلب النشر للجميع. (راجع شرط جوجل الحالي في Play Console → Dashboard.)
- حسابات المنظمات (Organization) غالباً معفاة من هذا الشرط.

### 5.2 أنشئ التطبيق
**Create app** ← الاسم «المصحف» ← اللغة العربية ← تطبيق ← مجاني.

### 5.3 قسم «App content» (املأه كاملاً)
- **Privacy policy**: انشر الملف `public/privacy-policy.html` (بعد وضع بريدك فيه) على رابط عام، مثلاً بنشر المشروع على Netlify/Vercel ثم الرابط `https://موقعك/privacy-policy.html`، أو عبر GitHub Pages. ضع الرابط هنا.
- **Ads**: لا يحتوي إعلانات.
- **App access**: كل الوظائف متاحة بدون تسجيل دخول.
- **Content rating**: ملأ الاستبيان (لا عنف/محتوى حساس) فيخرج تصنيف عام.
- **Target audience**: 13 سنة فأكثر (أو الكل) حسب رغبتك. إن اخترت أطفالاً ستنطبق سياسات إضافية.
- **Data safety**: لا نرسل الموقع أو أي بيانات شخصية إلى خادم. الموقع يُعالَج على الجهاز فقط، والإعدادات محلية. اختر ما يناسب ذلك، مع الإشارة إلى أن التطبيق يتصل بخوادم صوتيات خارجية (دون إرسال بيانات شخصية). **المسؤولية القانونية للإجابات عليك**، راجع تعريف «Collected» في Play Console.
- **Permissions**:
  - الموقع (foreground فقط): «لحساب مواقيت الصلاة واتجاه القبلة».
  - المنبّهات الدقيقة (`SCHEDULE_EXACT_ALARM`): قد يطلب Play Console إقراراً. الوظيفة الأساسية للتطبيق هي «تنبيهات مواقيت الصلاة في وقتها». إن رُفض الطلب أخبرني وأعدّل لاستخدام تنبيهات غير دقيقة.
- **Government apps / Financial / Health**: لا.

### 5.4 صفحة المتجر (Store listing)
- العنوان: «المصحف – القرآن ومواقيت الصلاة» (30 حرفاً كحدّ أقصى)
- وصف قصير (80 حرفاً): «القرآن الكريم وتفسيره ومواقيت الصلاة والأذكار بدون إنترنت»
- وصف كامل: اذكر الميزات (القرآن وتفسير الميسر، المواقيت بعدة طرق حساب، التنبيهات، القبلة، الأذكار، السبحة، التلاوات، يعمل أوفلاين، بدون إعلانات).
- الأيقونة: `play-store/icon-512.png`
- Feature graphic: `play-store/feature-graphic-1024x500.png`
- لقطات الشاشة: **2 على الأقل** (8 كحد أقصى). التقطها من هاتفك من الـ APK (الرئيسية، المصحف، المواقيت، الإعدادات).

### 5.5 الرفع
**Testing → Closed testing → Create track → Create new release** ← ارفع `app-release.aab` ← اكتب ملاحظات الإصدار ← **Save → Review → Start rollout**. ثم **Testers** ← أنشئ قائمة بريد وأضف 12+ مختبراً، وأرسل لهم رابط الاشتراك.
بعد انقضاء الشرط: **Dashboard → Apply for production** ثم أنشئ إصدار **Production** وارفع نفس الـ AAB (أو الأحدث).

> أول مراجعة قد تستغرق عدة أيام. ملف `app-release.aab` يجب أن يكون موقّعاً (إن رأيت تحذير «unsigned» في الـ workflow فالأسرار غير مضافة).

### 5.6 «Play App Signing»
عند أول رفع سيعرض عليك Play تفعيل Play App Signing. وافق (الموصى به). مفتاحك `upload.keystore` يكون مفتاح الرفع فقط، وإن ضاع يمكن استعادته عبر الدعم.

## 6) متطلبات تقنية مهمة تخص النشر الآن

- **API level**: Play يشترط حالياً استهداف Android 16 (API 36) للتطبيقات الجديدة والتحديثات. استخدمنا Capacitor 8 الذي يستهدف 36 افتراضياً.
- **16KB page size**: يُشترط للتطبيقات ذات الكود الأصلي؛ تطبيقنا بدون مكتبات native خاصة بنا، وCapacitor 8 محدّث لذلك.
- **معرّف الحزمة** `com.quran.almumin.app` لا يمكن تغييره بعد النشر. إن أردت معرفاً يخص نطاقك، غيّره في `capacitor.config.json` **قبل** أول رفع.

## 7) تحديث التطبيق لاحقاً

2. شغّل الـ workflow بـ `version_code` أكبر (2، 3...).
3. في Play Console: أنشئ إصداراً جديداً وارفع الـ AAB الجديد.

## 8) حلول المشاكل الشائعة

| العَرَض | الحل |
|---|---|
| فشل `npm install` | أرسل نص الخطأ؛ غالباً رقم نسخة مكتبة |
| `Development build detected` | تأكد أن الأمر `npm run build` (لا `dev`) |
| الـ AAB «unsigned» | أضف الأسرار الأربعة في الخطوة 3.3 |
| Play يرفض: `version code already used` | ارفع `version_code` |
| الإشعارات لا تصل | اسمح بـ «المنبّهات والتذكيرات»، وعطّل توفير البطارية للتطبيق، وافتح التطبيق مرة |
| الأيقونة افتراضية | تأكد أن خطوة `Launcher icons + splash` نجحت في الـ workflow |
